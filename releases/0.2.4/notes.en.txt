When an update would not install, Astra said nothing useful. It now names the
reason on the card itself — not "not installed", but what the server actually
answered. This release exists because of one such report: a person saw a red line
and had no way to say what to do about it.

Version comparison is fixed alongside it. A version string it could not parse
made Astra decide quietly that you already had the newest build, so no update was
offered at all. That case is now visible.

The companion switch showed itself inverted — on looked off. The cause was not
the highlight but the state being read before it had finished being written.

Signing in no longer misleads. When an old token did not fit, what surfaced was a
JSON parsing error, which reads as a broken product rather than as "sign in
again".

Your support bundle is readable again: the speech recogniser's own chatter had
been crowding everything else out of it.

In chat: a warning when the context fills up, a fix to how it is compacted, and
earlier conversations opening again after the interface updates.

The one prompt this installer can raise is now raised where somebody can see it
to answer.
