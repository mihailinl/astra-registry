Astra now checks for updates every time it starts, as soon as you are
signed in, and every six hours after that; when the update server cannot be
reached, it tries again within minutes. An update it finds is on screen as
soon as the window opens. Before, the first check ran a minute after
starting whether or not you were signed in, and one that failed was not
retried for six hours. Astra still never checks while you are signed out.

Settings has a new Updates section. It shows the installed version, when
Astra last checked and what it found, and a Check for updates button. When a
check fails, the reason is written there with a button to copy it; before,
"up to date" and "the updater is broken" looked exactly the same. While an
update is offered, Update and restart is there too, and the update banner
gains a Details button that opens this section.

An update that fails to install no longer leaves the window on
"Installing…" until you restart Astra: the failure reaches the screen.
Later now hides an update until Astra next starts, not for good. A copy you
added to Steam as a non-Steam game is no longer mistaken for the Steam
version, so it checks for updates too. With an app passcode, an update found
while Astra is locked is announced when you unlock it instead of being lost.
On Steam nothing changes: Steam keeps Astra up to date.

Deleting your chats while Astra was still speaking a reply could leave voice
and typing broken until a restart: the window picked the deleted chat back
up, and everything you said or typed after that went to a chat that no
longer existed. Deleting a chat now stops whatever is running in it,
including the reply being spoken, and nothing can bring the chat back. A
message sent to a chat that is gone starts a new one and says so, and a send
that is refused puts your words back. The overlay does the same. Deleting a
chat or clearing all memories also stops a memory pass already under way,
which could otherwise still save memories from what you had just removed.

On Windows, updating a plugin failed for any plugin that had ever written to
its log, with an "access denied" error that explained nothing: Astra held the
log open inside the plugin's folder, and Windows would not move that folder.
The log now lives in Astra's logs folder, so the update goes through and the
log survives the update it describes. An update error on a plugin card can
now be copied.

There is a new Account tab: your plan's limits, where your usage went, and
what each plan includes. Sign out has moved there from the account menu in
the status bar. When your plan's allowance runs out, the chat now says so in
a full sentence with a View plans button, instead of a generic error with
the reason hidden in a tooltip. The notice that Astra has switched to the
local voice for the same reason stays until you close it, and offers the
same button.

Three changes for plugins that talk to Astra, such as a game chat or a
messenger bridge. A plugin is now told which chat asked it to do something
and can answer there, not only in its own automation chat; a plugin has to
be updated to use this. A plugin's message that arrives while Astra is
answering you waits until Astra has finished, and is never merged with your
words into one request. And automation chats are no longer grouped after
all of yours, where the one being written to was hard to find: there is one
list, ordered by last activity.

Your saved sign-in is now checked more strictly, against a key built into
Astra, before it is trusted. Nothing is asked of you: an existing sign-in
carries over, and nobody has to sign in again.

On Linux, the weekly job that keeps Astra's package source in order failed
on every machine before doing anything; it runs now. The rpm packages are
signed from this release on, so the first update to 0.2.6 on Fedora and
other rpm systems has to accept Astra's signing key once, and an unattended
update skips it: run this one by hand and accept the key. Settings, Updates
now shows the state of the package source, with the button that fixes it
when something needs fixing, and says nothing about it on a copy that did
not come from the package.
