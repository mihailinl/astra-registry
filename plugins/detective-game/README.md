# Детектив для Astra

## Совместимость

Linux и macOS — **экспериментальные**. Проверки Python и автоматические тесты не заменяют проверку графики, звука и работы внутри Astra на реальной ОС. Windows сохраняет прежние возможности.

Официальные хосты Astra сейчас доступны для Windows x64 и Linux x64. Код подготовлен также под macOS, но официального хоста Astra для Mac и ARM пока нет: установить и полноценно проверить плагин там внутри Astra нельзя. См. [платформы Astra](https://github.com/mihailinl/AstraPlugins/blob/master/docs/en/1-orientation/platforms.md).

Игровые правила и сохранения не требуют Windows API. На Linux используется `$XDG_DATA_HOME/detective-game` (по умолчанию `~/.local/share/detective-game`), на macOS — `~/Library/Application Support/detective-game`. Существующие сохранения в прежней папке продолжают использоваться. `ASTRA_DETECTIVE_DATA_DIR` имеет приоритет. На Windows путь `%APPDATA%/detective-game` сохранён.

Игра-расследование в чате с Астрой. Попросите начать дело, осматривайте места, допрашивайте подозреваемых, оценивайте версии по найденным уликам и предъявляйте обвинение. Можно играть в окне Astra или через [официальный Telegram Bot](https://github.com/mihailinl/AstraPlugins/tree/master/examples/telegram-client), который пересылает сообщения в беседу Astra.

❗❗❗ Важно: Для использования всех функций загрузите Source code (zip) через режим разработки Astra. Подробные шаги — в разделе [«Установка из исходников»](#установка-из-исходников).

## Как играть

Напишите Астре, например:

1. «Начни новое детективное дело с 10 подозреваемыми» или «Хочу расследовать саботаж».
2. «Покажи дело» — Астра назовёт места, подозреваемых и собранные улики.
3. «Осмотри пультовую», «Допроси Сергея об алиби» или «Спроси Марину про мотив».
4. «Оцени версии» или «Дай подсказку».
5. «Обвиняю Сергея», когда соберёте доказательства.

Каждое дело получает код. Сохраняйте его: если одновременно открыто несколько дел, он помогает Астре выбрать нужное. Когда тема допроса не указана, вопрос будет об алиби. Если код опущен и подозреваемый встречается только в одном сохранённом деле, плагин найдёт его сам; при нескольких совпадениях попросит код. Неверное обвинение не заканчивает расследование.

## Какие бывают дела

По умолчанию создаётся новое процедурное дело: кража, убийство, саботаж, вымогательство или подлог. Генератор выбирает от 10 до 18 подозреваемых; по запросу можно задать от 8 до 24. Для каждой партии отдельно выбираются виновный, ложный след, свидетель, мотив, предмет, физический след, пропуск и улики. Комбинаций очень много, хотя буквальная математическая бесконечность невозможна.

В процедурном деле нужна цепочка из следа на месте, записи доступа и предмета со совпадающим следом. Версии рассчитываются из равных начальных шансов: каждая открытая улика умножает правдоподобие соответствующих подозреваемых, затем значения нормируются до 100%. Это игровая оценка, а не криминалистическая статистика; зависимые улики могут завышать уверенность.

Каждое дело получает случайный код и сохраняется в `%APPDATA%\detective-game\games.json` (на Linux — в `~/.local/share/detective-game/`). 

## Установка

Скачайте файл `detective-game-<версия>-noarch.astraplugin` из [Releases](https://github.com/Voltur792/detective-game/releases) и импортируйте его в Astra через интерфейс плагинов. Для игры в Telegram отдельно установите и настройте официальный Telegram Bot для Astra: ему нужны бот, группа с темами и доступ к Telegram API. Сам «Детектив» токен Telegram не запрашивает.

### Установка из исходников

Инструкция для Windows.

1. Откройте [последний релиз](https://github.com/Voltur792/detective-game/releases/latest), раскройте **Assets** и скачайте **Source code (zip)**. Архив исходников загружается как папка через Dev; выбирать его в окне импорта `.astraplugin` не нужно.
2. Распакуйте ZIP полностью в постоянную папку, например `C:\AstraPlugins\detective-game`. Откройте распакованную папку и найдите **`plugin.toml`** рядом с **`src`** и **`requirements.txt`**. Если архив создал ещё одну вложенную папку, выбирайте именно её.
3. В Astra откройте **Настройки → Приватность** и включите **«Разрешить неподписанные плагины»** для загрузки исходников.
4. Перейдите в **Плагины → Разработка (Plugins → Dev) → Загрузить плагин → Обзор**. Выберите папку с `plugin.toml` либо вставьте её полный путь в поле **Load a plugin** и нажмите загрузку.
5. Подтвердите запрашиваемые разрешения и дождитесь подготовки Python и зависимостей. Для первой установки нужен интернет; не закрывайте Astra до завершения.
6. Найдите плагин в **Установленных (Installed)** и включите его, если он выключен. После перезапуска Astra плагин из папки нужно включать снова.

Плагин запускается прямо из исходников Python; отдельная сборка не требуется. Если Astra сообщает, что Python не найден, установите 64-разрядный Python **3.10 или новее** и полностью перезапустите Astra.

**Если загрузка не удалась:** проверьте, что ZIP распакован целиком и выбрана папка с `plugin.toml`. При ошибке установки зависимостей проверьте интернет и откройте журнал в карточке плагина; ошибка `No module named ...` означает, что зависимости не подготовились. Установка пакетов в другой Python на компьютере не исправит окружение, которым Astra запускает плагин.

После загрузки напишите в чате Astra: **«Начни новое детективное дело»**. Для игры через Telegram отдельно настройте официальный Telegram Bot; у самого «Детектива» нет поля для Telegram-токена.

**Обновление из исходников:** распакуйте новый архив в отдельную постоянную папку, выключите старую копию, загрузите новую через Dev и включите плагин. Если настройки хранились в папке старой копии, сохраните её до переноса настроек. Не перемещайте и не удаляйте активную папку: Astra продолжает запускать код из неё.
