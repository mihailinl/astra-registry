# Голосовой наборщик текста — Voice Text Input

Плагин [Astra](https://github.com/mihailinl/AstraPlugins) для голосового набора
в активное текстовое поле: мессенджер, браузер, документ или другое приложение.
Поддерживает обычную диктовку на русском и английском и локальный перевод
**с русского на английский и с английского на русский**.

> **Машинный перевод может ошибаться**, менять смысл, неточно передавать имена,
> числа и специальные термины. Ошибки распознавания речи также влияют на перевод.
> Проверяйте текст перед отправкой, особенно если точность важна.

> **Linux и macOS — экспериментальная поддержка.** Полная ручная проверка на
> этих ОС ещё не выполнена; для macOS пока нет выпускаемого хоста Astra.
> Зависимости и ограничения: [PLATFORMS.md](PLATFORMS.md).

## Что нового в 1.5.0

- Обычная диктовка на английском с английскими голосовыми командами.
- Перевод целых фраз после паузы между русским и английским языками.
- Настраиваемые фразы включения и выключения перевода.
- «Отмена» больше не завершает диктовку; в переводе убирает только последнюю фразу.
- Резервное скачивание моделей перевода с Яндекс Диска.
- Исправлена загрузка моделей перевода в профилях Windows с кириллицей в имени.

## Установка и первый запуск

1. В Astra откройте **Плагины → Каталог (Browse)**, найдите **Voice Text Input**
   и нажмите **Установить**.
2. Включите плагин и откройте его настройки.
3. Выберите **«Язык прослушивания»**: `ru` для русского или `en` для английского.
4. Дождитесь первой загрузки модели, поставьте курсор в нужное текстовое поле
   и скажите **«напиши привет»** или **“write hello”**.

Для первой установки и загрузки моделей нужен интернет. Затем обычная локальная
диктовка и перевод работают без сети. Обновления устанавливаются через Astra.
Последние выпуски также доступны в [GitHub Releases](https://github.com/Voltur792/voice-text-input/releases).

## Голосовые команды

Слушается **только выбранный язык**; автоматического переключения между русским
и английским нет. Стандартные команды меняются вместе с языком прослушивания.
Если вы задали собственную фразу в настройках, используется она.

| Действие | Русский (`ru`) | Английский (`en`) |
| --- | --- | --- |
| Начать обычный набор | «напиши» | “write” |
| Включить перевод | «включить перевод» | “start translation” |
| Выключить перевод и продолжить обычный набор | «выключить перевод» | “stop translation” |
| Отправить и продолжить диктовку | «отправить» | “send” |
| Отправить и завершить диктовку | «закончить» | “finish” |
| Стереть текст; в переводе — отменить последнюю фразу | «отмена» | “cancel” |
| Перенести строку без отправки | «с новой строки» | “new line” |

Команду начала произносите в начале фразы, команды отправки, завершения,
отмены и переноса строки — в конце или отдельной репликой. Слово «отправить»
в середине диктуемого текста само по себе сообщение не отправляет.

Обращение **«Астра, напиши…»** предназначено ассистенту Astra. Для плагина
произносите **«напиши…»** без обращения. Отключать голосовую активацию Astra
для этого не требуется.

## Обычный голосовой набор

Текст появляется **по мере речи**. После паузы выбранный движок может уточнить
распознанную фразу и пунктуацию. По умолчанию используется локальный
`faster-whisper`; вариант `vosk` работает без дополнительного уточнения.

Например: «напиши привет запятая как дела вопросительный знак». Голосовая
пунктуация русского языка доступна в режиме Vosk; Whisper также добавляет
пунктуацию при уточнении.

«Отправить» нажимает Enter и оставляет диктовку включённой — следующую фразу
можно говорить без нового «напиши». «Закончить» отправляет текст и завершает
диктовку. «С новой строки» вставляет перенос без отправки в мессенджерах.

## Перевод

**Переводится только фраза целиком после паузы.** Промежуточные слова и исходный
текст в активное окно не печатаются. Перевод использует распознанный Vosk текст;
уточнение Whisper относится к обычной диктовке.

| Язык прослушивания | Направление | Включение |
| --- | --- | --- |
| `ru` | Русская речь → английский текст | «включить перевод» |
| `en` | Английская речь → русский текст | “start translation” |

Пример: выберите `ru`, скажите «включить перевод», затем «Я буду дома через
двадцать минут» и сделайте паузу. В текстовом поле появится английский перевод.
Включить перевод можно и во время обычной диктовки, начав новую фразу.

При первом включении скачивается модель выбранного направления, примерно
**70 МБ**. Дождитесь готовности: первая загрузка может занять несколько минут.
Дальше фразы обрабатываются локально на процессоре. «Отправить» дожидается
предыдущих переводов; при ошибке перевода сообщение автоматически не отправляется.
Для длинных реплик делайте паузы чаще.

Чтобы вернуться к обычному набору, скажите **«выключить перевод»** или
**“stop translation”**. Уже продиктованные фразы дождутся перевода, текст
сохранится, Enter не нажмётся. Можно сразу продолжать обычную диктовку.
Команда «напиши» / “write” также возвращает обычный набор, отменяя ещё не
полученные переводы.

**Обычный набор не скачивает и не загружает дополнительные модели перевода.**
Они загружаются только при включении перевода и выгружаются при выходе из него.
Скачанные файлы остаются на диске для следующего включения.

### Как работает «отмена»

- **В обычной диктовке** стирает текущий набранный текст и оставляет диктовку включённой.
- **В переводе** убирает только последнюю фразу, включая её разделитель. Предыдущие
  фразы сохраняются, перевод остаётся включённым, модель не выгружается.
- Если последняя фраза ещё переводится, отменяется именно она; её поздний результат
  не появится снова.
- Если сказать «новая фраза отмена», эта ещё не напечатанная реплика отбрасывается.
- Одно произнесённое «отмена» выполняется один раз. Повторная команда после паузы
  позволяет убрать предыдущую фразу. Уже отправленные сообщения не стираются.

На английском те же действия выполняет **“cancel”**. Для выхода из перевода
используйте «выключить перевод» / “stop translation”, а для завершения диктовки —
«закончить» / “finish”.

## Настройки

Настройки находятся в **Astra → Плагины → Voice Text Input**.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Включено | да | Прослушивание микрофона и диктовка |
| Язык прослушивания | `ru` | `ru` / `en`; определяет язык распознавания, стандартные команды и направление перевода |
| Слово начала диктовки | `напиши` | При `en` — `write`; можно задать свою фразу |
| Слово отправки | `отправить` | При `en` — `send`; Enter и продолжение диктовки |
| Слово завершения | `закончить` | При `en` — `finish`; Enter и конец диктовки. Пустое значение: команда отправки сама завершает диктовку |
| Слово отмены | `отмена` | При `en` — `cancel`; стирает текст или последнюю переводимую фразу, сохраняя режим |
| Слово переноса строки | `с новой строки` | При `en` — `new line`; перенос без отправки. Пустое значение отключает команду |
| Фраза включения перевода | `включить перевод` | При `en` — `start translation`; можно изменить или отключить пустым значением |
| Фраза выключения перевода | `выключить перевод` | При `en` — `stop translation`; возвращает обычный набор без Enter; можно изменить или отключить |
| Движок распознавания | `faster-whisper` | Локальные `faster-whisper` / `vosk` или облачные `yandex` / `openai` / `google` |
| Модель Whisper | `small` | `tiny` / `base` / `small` |
| Уточнение текста после пауз | да | Перепроверка обычной диктовки выбранным движком |
| Ожидание коррекции перед отправкой | 1,2 с | `0` — отправлять без ожидания уточнения; перевод дожидается готовых фраз независимо от этой настройки |
| Клавиша отправки | `enter` | `enter` / `ctrl+enter`, в соответствии с настройками мессенджера |
| API-ключ Яндекс SpeechKit | — | Для облачного движка `yandex` |
| Язык SpeechKit | `ru-RU` | Язык облачного распознавания Яндекса |
| API-ключ OpenAI | — | Для OpenAI или совместимого сервиса |
| OpenAI-совместимый сервер | `https://api.openai.com/v1` | Адрес выбранного сервиса распознавания |
| Модель OpenAI | `whisper-1` | Название модели выбранного сервиса |
| API-ключ Google Cloud STT | — | Для облачного движка `google` |

При выборе облачного движка звук для уточнения передаётся выбранному сервису;
требуются его API-ключ, доступ к сети и возможная оплата по условиям сервиса.
Локальный режим и перевод облачного ключа не требуют.

## Загрузка моделей

Модели скачиваются автоматически по мере необходимости:

- Vosk для русского — около **45 МБ**, для английского — около **40 МБ**.
  В памяти используется модель выбранного языка прослушивания.
- Whisper — при использовании этого движка; размер зависит от выбранной модели.
- Перевод — около **70 МБ на направление**, только после команды включения.

Если основной источник моделей перевода недоступен, плагин автоматически
пробует [зеркало Яндекс Диска](https://disk.yandex.ru/d/CeRqoRrXAcNKzA).
Для зеркала не нужен аккаунт Яндекса. Загруженные архивы проверяются по
контрольным суммам; незавершённая загрузка не принимается за готовую модель.
Источник, прогресс и возможные ошибки видны в журнале плагина.

## Ограничения

- **Распознавание речи и машинный перевод могут ошибаться.** Проверяйте готовый текст.
- Плагин печатает в поле с текущим фокусом. Если переключить окно, ввод пойдёт туда.
- Ручные правки текста в окне не учитываются при отмене.
- Окна, запущенные от администратора, могут не принимать ввод от Astra с обычными правами.
- При постоянном прослушивании Astra слышит те же фразы и может ответить на них.
