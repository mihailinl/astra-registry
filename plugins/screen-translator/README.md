# Перевод с экрана — плагин для Astra

Переводит любой текст на экране: выдели область горячей клавишей — перевод появится рядом. Или включи
живые субтитры для диалогов в играх и видео. Текст распознаёт сама Windows прямо на компьютере; в
переводчик уходит только распознанный текст, не картинка.

## Установка

1. Скачай `screen-translator-*.astraplugin` из [последнего релиза](../../releases/latest).
2. Astra → **Мастерская** → **Разработка** → **Импорт плагина** → **Выбрать файл…** → выбери файл → **Установить**.
3. Страница плагина — вкладка **Перевод с экрана** в верхнем меню Astra.

Нужна Windows 10 (2004) или 11.

## Как пользоваться

| Клавиши (по умолчанию) | Что делает |
|---|---|
| `Ctrl+Alt+T` | Экран замирает — выдели мышкой текст. Перевод появится под ним, с кнопками «копировать», «озвучить», «закрыть». |
| `Ctrl+Alt+Y` | Субтитры: выдели один раз область, где появляется текст. Каждая фраза переводится сразу, последние стоят друг под другом. Нажми ещё раз — выключить. |
| `Ctrl+Alt+W` | Перевести всё активное окно. |

Голосом: «переведи, что на экране», «переведи вот это», «включи субтитры».

Окно субтитров можно перетащить мышкой — место запомнится. Или выбери на странице плагина: поверх
выбранной области (перекрывает оригинальные субтитры), под ней, над ней, внизу экрана.

## Настройки

На странице плагина:

- **Горячие клавиши** — Ctrl / Alt / Shift / Win и любая клавиша.
- **Язык текста на экране** — «Автоматически»: каждая строка читается всеми языками, что есть в
  Windows, и берётся самое похожее на слова. Поэтому английские субтитры рядом с русской подсказкой
  браузера читаются правильно, а мусор из картинки видео отбрасывается.
- **Переводить на** — русский, английский, украинский и другие.
- **Переводчик** — Google (бесплатно, без ключа) или DeepL (нужен бесплатный ключ с deepl.com/pro-api).
- **Как показывать** — размер шрифта, когда скрывать перевод, как часто читать субтитры и сколько
  последних фраз показывать, показывать ли оригинал, копировать ли перевод в буфер.
- **Astra читает перевод вслух** — переведённая область озвучивается голосом Astra целиком, частями
  по предложениям. Плагин создаёт для этого команду Astra (кнопка на странице), она заработает после
  перезапуска Astra.

## Нет нужного языка?

Windows распознаёт языки, которые у неё установлены. Японский, китайский, корейский и другие ставятся
бесплатно: **Параметры → Время и язык → Язык и регион → Добавить язык**. Или в PowerShell от имени
администратора:

```powershell
Add-WindowsCapability -Online -Name "Language.OCR~~~ja-JP~0.0.1.0"
```

После установки перезапусти плагин.

## Что нужно знать

- Окна перевода скрыты от захвата экрана: так субтитры не читают сами себя. Поэтому перевод не виден
  на скриншотах и в OBS.
- Поверх игры в эксклюзивном полноэкранном режиме Windows ничего не показывает — включи в игре режим
  «окно без рамки» (borderless).
- Бесплатный переводчик Google — неофициальный вход; если Google его ограничит, переключись на DeepL.

## Приватность

- Распознавание текста — локально, средствами Windows. Снимки экрана никуда не отправляются и не
  сохраняются на диск.
- В выбранный переводчик (Google или DeepL) уходит только распознанный текст.
- Настройки лежат в `%APPDATA%\astra\screen-translator\settings.json`.

## Разработка

```bash
bun install
npm test                       # 9 тестов, в том числе настоящее распознавание Windows
astra-plugin check . --strict
astra-plugin build .
```

- `src/overlay.ps1` — фоновый помощник: горячие клавиши, выбор области, снимок, распознавание
  (Windows.Media.Ocr), окна поверх игр. Вшивается в бандл как текст (`--loader:.ps1=text`) и при
  запуске пишется в `%APPDATA%\astra\screen-translator\`.
- `src/helper.ts` — общение с помощником (JSON-строки через stdin/stdout).
- `src/translate.ts` — Google / DeepL, кэш, сравнение строк для субтитров.
- `src/index.ts` — плагин: настройки, клавиши, субтитры, инструменты для ИИ, страница.

Релиз: `astra-plugin version 0.2.0`, коммит, `git tag v0.2.0 && git push --tags` — остальное делает
GitHub Actions (`.github/workflows/release.yml`).
