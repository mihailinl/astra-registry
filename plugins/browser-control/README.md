# Astra Browser Control

> **Linux и macOS — экспериментальная поддержка.** Полная ручная проверка на этих ОС ещё не выполнена. Для macOS пока нет выпускаемого хоста Astra. Зависимости и ограничения: [PLATFORMS.md](PLATFORMS.md).

Плагин для управления браузером голосом через Astra. В базовом режиме он открывает сайты и поисковые запросы. С расширением Astra работает со вкладками, страницами, видео и звуком.

## Возможности

- **Сайты и поиск** — «Открой YouTube», «Найди погоду в Казани». Поисковик выбирается на вкладке «Браузер»: Яндекс, Google, DuckDuckGo или Bing. Работает без расширения, в том числе в Firefox.
- **Вкладки во всех окнах** — показать, переключиться, закрыть одну или несколько, закрыть все кроме текущей, закрепить, вернуть закрытую. Номера берутся из показанного списка, поэтому закрывается именно названная вкладка.
- **Страницы** — прочитать текст (длинные страницы — частями), найти слово, нажать кнопку или ссылку по надписи, ввести и стереть текст в поле, отправить по Enter, прокрутить, вернуться назад или обновить.
- **Видео и звук** — «Включи на ютубе лофи для работы» одной командой; список видео на странице с номерами и запуск по номеру или названию; пауза и продолжение; выключение и включение звука вкладок.
- **Режим просмотра шортсов** — листание Shorts, Reels и TikTok короткими словами без «Астра» (подробнее ниже).
- **Быстрые команды без ИИ** — действия плагина можно привязать к фразам в редакторе команд Astra: «дальше», «назад», «пауза видео», «выключи звук» и другие срабатывают сразу, не расходуя запрос к модели.

## Что нового в 1.2.0

- Настройка просмотра шортсов больше не исчезает при обновлении статуса в базовом режиме. Для управления видео по-прежнему нужно подключённое расширение браузера.
- Перед включением шортсов с кнопки проверяется связь с расширением, чтобы микрофон не запускался без подключения.
- Добавлена кнопка «Помощь / поддержка» для создания обращения на GitHub.
- Упрощена шапка вкладки; кнопка поддержки оформлена в общем фиолетовом стиле.
- Из инструкции удалена установка плагина из исходников: используйте готовый файл `.astraplugin` из релиза.

## Скачать

Последняя версия для Windows x64 находится в [Releases](https://github.com/Voltur792/browser-control/releases/latest). Скачайте файл `.astraplugin` и установите его через Astra.

## Подключить браузер

1. В Astra откройте вкладку **«Браузер»**, выберите браузер и режим **«С расширением»**.
2. Нажмите **«Установить расширение»**. Установщик откроет папку расширения и попробует открыть страницу его настроек.
3. Если откроется пустая вкладка, скопируйте адрес из инструкции в Astra и вставьте его в адресную строку браузера:
   - Яндекс Браузер: `browser://extensions/`
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
   - Opera: `opera:extensions`
   - Vivaldi: `vivaldi://extensions/`
4. Включите **Режим разработчика**, выберите **«Загрузить распакованное расширение»** и укажите открытую установщиком папку.
5. Перезапустите браузер и нажмите **«Проверить подключение»** в Astra.

Firefox работает только в базовом режиме.

- «Перейди на вкладку ВКонтакте»
- «Найди на странице кнопку Войти и нажми»
- «Найди поле поиска и введи погода»

- «Включи на ютубе лофи для работы»
- «Включи видео про котиков» (на уже открытой странице с видео)

- «Вернись назад», «Обнови страницу», «Верни закрытую вкладку»
- «Закрой все вкладки, кроме этой», «Закрепи вкладку»

## Режим просмотра шортсов

Скажите «Астра, просмотр шортсов» — плагин сам начнёт слушать микрофон и понимать короткие слова **без «Астра»**: «дальше», «назад», «пауза», «продолжи», «выключи звук», «включи звук». Работает для YouTube Shorts, Instagram Reels и TikTok в подключённом браузере. «Закончить просмотр» выключает режим; он выключается и сам после 15 минут без команд. Включение и выключение сопровождаются коротким сигналом, состояние видно на вкладке «Браузер».

Распознавание локальное (Vosk, ~45 МБ, без интернета после загрузки модели). Если установлен плагин «Голосовой наборщик текста», используется его модель; иначе она скачивается один раз.

Чтобы включать режим и листать без обращения к ИИ, создайте в редакторе команд Astra команду с фразой «просмотр шортсов» и действием «Браузер: включить режим просмотра шортсов». Так же можно привязать остальные действия плагина «Браузер: …».

## Обновление расширения

Новые команды требуют расширение версии **1.0.0**. Если вкладка «Браузер» просит обновить расширение, нажмите «Установить расширение», затем «Обновить» на карточке Astra Browser Control на странице расширений браузера.

## Разрешения

- Плагин не запрашивает разрешений Astra и общается только со своим расширением через локальное соединение на этом компьютере.
- Микрофон используется только во включённом режиме просмотра шортсов; звук распознаётся на компьютере и никуда не отправляется.
- Расширение браузера: `nativeMessaging` — связь с плагином; `tabs` и `scripting` — вкладки и действия на странице; `sessions` — «верни закрытую вкладку»; доступ к HTTP/HTTPS-сайтам — чтение и действия на странице по вашей команде.

## Удаление

1. Удалите расширение на странице расширений браузера.
2. Чтобы убрать связь расширения с плагином, в PowerShell из папки плагина выполните `./install-extension.ps1 -Remove`.
3. Удалите плагин в Astra.

## Приватность

Расширенный режим работает только после команды пользователя. История вкладок не собирается в фоне. Поля ввода исключаются из чтения; распознанные поля паролей, кодов подтверждения и платёжных карт блокируют чтение и действия на странице. Типичные секреты фильтруются до передачи в Astra. Произвольный секрет, показанный обычным текстом без распознаваемых признаков, нельзя гарантированно отличить от обычного содержимого.

Обмен между Astra и расширением идёт через локальное соединение на этом компьютере с проверкой случайного секрета. Данные страниц не отправляются внешним сервисам плагина.
