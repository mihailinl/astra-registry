# Web Speech-to-Text — Free STT Plugin for Astra

Speech recognition via Web Speech API — **free, no API key required**.

![icon](https://raw.githubusercontent.com/LilKALINOV/Astra-Google-STT/4f672cbf3d193805a00741a13a54de4c1d474e97/icon.png)

## How it works

This plugin uses the same free Web Speech API endpoint that Chrome and the Python `SpeechRecognition` library use. No registration, no API key, no setup.

**Limitations:**
- Audio up to ~60 seconds per request
- Internet connection required (requests go to Google servers)
- Supports 38 languages

## Installation

1. In Astra: **Settings → Privacy** → enable **"Allow unsigned plugins"**
2. **Plugins → Dev** → paste the plugin folder path and click Load
3. Done! The plugin works immediately, no configuration needed
