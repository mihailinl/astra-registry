# \# 🎮 GameBuddy — твой игровой компаньон в Astra

# 

# \*\*GameBuddy\*\* — плагин для Astra, который связывает игровую активность со Steam и помогает превратить её в часть общения с дружелюбным ИИ-компаньоном.

# 

# Следи за игровыми сессиями, узнавай, во что играешь, просматривай статистику и делись игровыми моментами — а Astra будет рядом, чтобы поддержать разговор, поинтересоваться твоими успехами и немного подшутить над очередным игровым марафоном. 💜

# 

# \## ✨ Возможности

# 

# \- 🔗 \*\*Подключение Steam\*\* — привязка аккаунта с помощью восьмизначного кода через интерфейс плагина.

# \- 🟢 \*\*Игровая активность\*\* — просмотр статуса Steam, текущей и недавней игровой активности.

# \- ⏱️ \*\*Статистика\*\* — информация о времени в играх и библиотеке Steam.

# \- 🏆 \*\*Игровые достижения и моменты\*\* — запись побед, достижений и памятных событий для итогового отчёта.

# \- 🎮 \*\*Игровые сессии\*\* — отслеживание начала игры, переключений и завершения сессии на основе событий Astra.

# \- 💜 \*\*Общение с Astra\*\* — компаньон может реагировать на смену игры и обсуждать игровые приключения.

# 

# \## 🌌 Особенности

# 

# \- Неоновый интерфейс в игровом стиле.

# \- Интеграция со Steam через серверный обмен токенами.

# \- Автоматическое получение токена после ввода кода привязки.

# \- Русская и английская локализация.

# \- Интеграция с инструментами и событиями Astra.

# 

# \## 🧩 Инструменты Astra

# 

# Плагин предоставляет следующие инструменты:

# 

# \- `game\_coach` — игровой помощник.

# \- `current\_game\_session` — информация о текущей игровой сессии.

# \- `record\_game\_moment` — запись достижения, победы, забавного момента или другого события.

# \- `session\_report` — итоговый отчёт об игровой сессии.

# 

# \## ⚙️ Как работает отслеживание сессий

# 

# GameBuddy подписывается на события Astra `games\_changed` и `companion\_game\_changed`.

# 

# При обнаружении смены игры плагин может отправить приветственное сообщение в собственный диалог GameBuddy в Astra. При завершении сессии он может предложить подвести её итоги.

# 

# Ответ Astra обрабатывается в фоновом режиме, чтобы обработка игровых событий не задерживалась ожиданием ответа модели.

# 

# \## ⚠️ Ограничения

# 

# \- Astra не предоставляет фиксированную схему данных для игровых событий, поэтому названия игр извлекаются с помощью осторожного анализа доступных полей.

# \- Плагин не сканирует процессы Windows и самостоятельно не отслеживает запуск игр в Steam или других лаунчерах.

# \- Длительность сессии и записанные игровые моменты хранятся в памяти и сбрасываются при перезапуске процесса плагина.

# \- Автоматическая реакция на достижения возможна, только если соответствующие данные присутствуют в одном из получаемых событий. В остальных случаях достижения и игровые моменты можно записывать через `record\_game\_moment`.

# \- Сообщения отправляются при обнаружении переходов между играми и соответствующих игровых событий, а не при каждом уведомлении, чтобы не перегружать чат.

# 

# \## 🔐 Разрешения

# 

# GameBuddy использует следующие разрешения Astra:

# 

# \- `subscribe\_events` — подписка на события `games\_changed` и `companion\_game\_changed`.

# \- `send\_chat\_message` — отправка сообщений в собственный диалог GameBuddy в Astra. Это разрешение позволяет плагину инициировать сообщения, поэтому Astra может запросить согласие пользователя.

# \- `client` — возможность клиентской интеграции, необходимая для использования отправки сообщений.

# \- `push\_to\_ui` — обновление интерфейса плагина.

# 

# \## 🛠️ Разработка и тестирование

# 

# Для локальной разработки требуется Rust и CLI Astra.

# 

# ```bash

# cargo test

# astra-plugin locale sync

# astra-plugin check . --strict

# astra-plugin test .

# astra-plugin dev .

# ```

# 

# Команда `astra-plugin dev .` проверяет, собирает и загружает плагин в запущенный экземпляр Astra с поддержкой горячей перезагрузки. Для локальной загрузки необходимо включить Developer Mode в Astra.
