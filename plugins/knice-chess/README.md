# KNICE Chess

Шахматы против классического локального бота или выбранной в Astra модели в отдельной вкладке.

> Статус: независимый пользовательский (community) плагин. Это не официальный релиз Astra или Minice.

## Что есть в плагине

- полные шахматные правила: шах, мат, пат, рокировка, взятие на проходе и превращение пешки;
- четыре локальных уровня и уровень «ИИ Астры», который играет через выбранные в приложении провайдера и модель;
- расчёт ходов в Web Worker — интерфейс не зависает во время поиска;
- плавное перемещение фигур, включая рокировку, и щадящий режим `prefers-reduced-motion`;
- игра белыми или чёрными, отмена хода и локальное сохранение незаконченной партии;
- пошаговый просмотр истории партии с плавным движением фигур и переходом к началу, назад, вперёд и к текущей позиции;
- включённый по умолчанию режим «Реализм»: естественная пауза перед ходом, облако мыслей и меняющиеся шахматные реплики;
- локальные уровни по-прежнему работают без сети; «ИИ Астры» отправляет выбранному в Astra провайдеру FEN, историю и список легальных ходов, проверяя ответ до изменения доски;
- встроенный чат с «ИИ Астры»: соперник получает текущую позицию, помнит реплики своего плагинного диалога и может обсуждать партию.

Правила и валидация ходов основаны на библиотеке [chess.js](https://github.com/jhlywa/chess.js), распространяемой по лицензии BSD-2-Clause. В режиме «ИИ Астры» модели также доступен узкий tool `play_chess_move`: он принимает только один ход в UCI-нотации для активной партии.

## Разрешение для ИИ Астры

Уровень «ИИ Астры» и игровой чат требуют `send_chat_message`. Плагин отправляет выбранному в Astra провайдеру текущую позицию, историю ходов и сообщения игрового чата. Astra показывает это высокорисковое разрешение на экране согласия, а импортируемый вручную bundle с таким разрешением отклоняется. Для разработки используйте `astra-plugin dev .`; публичная сборка должна быть аттестована и опубликована через каталог Astra.

```bash
npm install
npm test
npm run typecheck
astra-plugin check --strict .
astra-plugin test .
```

Для загрузки в запущенную Astra:

```bash
astra-plugin dev .
```
