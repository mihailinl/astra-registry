# Astra Telegram Assistant

Плагин для интеграции Telegram с локальным ассистентом Astra.

## Возможности

- Приём текстовых сообщений от пользователей Telegram.
- Проверка доступа пользователей по списку разрешённых аккаунтов.
- Управление владельцем и разрешёнными пользователями через Telegram `@username`.
- Передача входящего сообщения в Astra для формирования ответа.
- Автоматическая отправка сформированного ответа обратно в Telegram.
- Озвучивание входящих сообщений и ответов средствами голосового движка Astra.
- Сохранение истории переписки бота.

## Как работает

1. Пользователь пишет Telegram-боту.
2. Плагин проверяет, разрешено ли этому пользователю взаимодействовать с ботом.
3. Текст сообщения передаётся Astra.
4. Astra формирует ответ.
5. Ответ автоматически отправляется пользователю в Telegram.
6. Astra может дополнительно произнести сообщение локальным голосом.

## Настройка

1. Создайте Telegram-бота через BotFather.
2. Укажите токен бота в настройках плагина.
3. Укажите Telegram `@username` владельца.
4. Запустите бота и отправьте ему `/start`.
5. Добавьте разрешённых пользователей, если это необходимо.
6. Убедитесь, что плагину разрешено отправлять сообщения в Astra.

## Ограничения

- Для привязки Telegram-аккаунта пользователь должен сначала открыть бота и отправить `/start`.
- Внутри Telegram используется текстовый обмен.
- Распознавание входящих голосовых сообщений Telegram штатным API плагина пока не поддерживается.
- Для работы необходим запущенный Astra и доступный Telegram Bot API.

## Безопасность

Не публикуйте токен Telegram-бота и не передавайте его посторонним. Добавляйте в список доступа только доверенных пользователей.
