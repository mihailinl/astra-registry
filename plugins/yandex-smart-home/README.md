# Yandex Smart Home

> **Linux и macOS — экспериментальная поддержка.** Полная ручная проверка на этих ОС ещё не выполнена. Для macOS пока нет выпускаемого хоста Astra. Зависимости и ограничения: [PLATFORMS.md](PLATFORMS.md).

Управляйте устройствами Умного дома Яндекса прямо из Astra — голосом и
текстом через ИИ, а также вручную через вкладку с переключателями.

English: An Astra plugin to control Yandex Smart Home devices from Astra —
via the built-in AI or a dedicated tab.

❗❗❗ Важно: Для использования всех функций начиная с версии 0.5.1 загрузите Source code (zip) через режим разработки Astra. Подробные шаги — в разделе [«Установка из исходников»](#установка-из-исходников).

## Возможности

- **Вкладка «Умный дом»** в панели навигации Astra:
  - *Устройства* — карточки всех устройств с переключателями вкл/выкл;
    сенсоры показывают показания (температура, напряжение, состояние АКБ…);
    состояние обновляется автоматически.
  - *Сценарии* — запуск любого сценария одной кнопкой.
  - *Голосовые команды* — свои точные фразы для устройств и сценариев,
    которые выполняются напрямую без запроса к ИИ.
  - *Виджеты* — настраиваемые окна на рабочем столе Windows с показателями
    датчиков дома, ЦП, ОЗУ и видеокарты.
  - *Настройки* — подключение к Яндексу по OAuth-токену со встроенной
    пошаговой инструкцией.
- **Инструменты для ИИ Astra**: включение/выключение устройств, запуск
  сценариев, списки устройств и сценариев — по обычной человеческой фразе.
  Плагин понимает русские падежи и разговорные обороты, находит устройство
  по названию и даже по комнате.
- **Прозрачный стеклянный интерфейс** в стиле темы Astra.
- **Приватность**: токен хранится локально и передаётся только в API
  Яндекса; ничего не отправляется куда-либо ещё.

## Установка из исходников

Инструкция для Windows.

1. Откройте [последний релиз](https://github.com/Voltur792/Y-home-f-astra/releases/latest), раскройте **Assets** и скачайте **Source code (zip)**. Архив исходников загружается как папка через Dev; выбирать его в окне импорта `.astraplugin` не нужно.
2. Распакуйте ZIP полностью в постоянную папку, например `C:\AstraPlugins\Y-home-f-astra`. Откройте распакованную папку и найдите **`plugin.toml`** рядом с **`src`** и **`requirements.txt`**. Если архив создал ещё одну вложенную папку, выбирайте именно её.
3. В Astra откройте **Настройки → Приватность** и включите **«Разрешить неподписанные плагины»** для загрузки исходников.
4. Перейдите в **Плагины → Разработка (Plugins → Dev) → Загрузить плагин → Обзор**. Выберите папку с `plugin.toml` либо вставьте её полный путь в поле **Load a plugin** и нажмите загрузку.
5. Подтвердите запрашиваемые разрешения и дождитесь подготовки Python и зависимостей. Для первой установки нужен интернет; не закрывайте Astra до завершения.
6. Найдите плагин в **Установленных (Installed)** и включите его, если он выключен. После перезапуска Astra плагин из папки нужно включать снова.

Плагин запускается прямо из исходников Python; отдельная сборка не требуется. Если Astra сообщает, что Python не найден, установите 64-разрядный Python **3.10 или новее** и полностью перезапустите Astra.

**Если загрузка не удалась:** проверьте, что ZIP распакован целиком и выбрана папка с `plugin.toml`. При ошибке установки зависимостей проверьте интернет и откройте журнал в карточке плагина; ошибка `No module named ...` означает, что зависимости не подготовились. Установка пакетов в другой Python на компьютере не исправит окружение, которым Astra запускает плагин.

После загрузки откройте **Умный дом → Настройки** и подключите аккаунт Яндекса по инструкции ниже. Для расписаний включите также **Sleep Pause Timer**. После добавления новых прямых голосовых фраз полностью закройте Astra, подождите несколько секунд и запустите снова.

**Обновление из исходников:** распакуйте новый архив в отдельную постоянную папку, выключите старую копию, загрузите новую через Dev и включите плагин. Если настройки хранились в папке старой копии, сохраните её до переноса настроек. Не перемещайте и не удаляйте активную папку: Astra продолжает запускать код из неё.

## Подключение (один раз)

1. Откройте вкладку «Умный дом» → «Настройки» — там полная инструкция.
2. Кратко: на oauth.yandex.ru создайте приложение типа
   «Для доступа к API или отладки», добавьте права `iot:view` и
   `iot:control` (Умный дом Яндекса), скопируйте ClientID.
3. Откройте ссылку авторизации со своим ClientID:
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENTID`
4. Вставьте показанный токен (начинается с `y0__`) в поле на вкладке
   «Настройки» и нажмите «Подключить».

## Прямые голосовые команды без ИИ

Свяжите свои фразы с устройствами и сценариями во вкладке «Голосовые
команды». При точном совпадении команда выполняется сразу, без обращения
к ИИ. Можно задать несколько вариантов фразы; обращение «Астра»
поддерживается автоматически.

Команды можно редактировать, отключать и удалять. Действие и значение
уже добавленной команды меняются без перезапуска. Новые фразы применяются
после повторного запуска Astra.

## Настольные виджеты

Соберите свой виджет для рабочего стола Windows из показателей устройств,
включая раздел «Только просмотр»: температуры, влажности, заряда,
напряжения, движения и других доступных значений. В одном виджете можно
объединить несколько устройств с показателями ЦП, ОЗУ и видеокарты.
Добавляйте свои подписи и меняйте порядок показателей.

Настраиваются цвет фона, текста и шкал, прозрачность, ширина, размер текста,
скругление углов и показ поверх других окон. Для фона можно выбрать свою
картинку PNG, JPG или WebP. 

Показания обновляются с интервалом от одной секунды. Виджеты поддерживают перетаскивание, сохранение позиции,
скрытие и повторный показ. Можно создать до восьми виджетов с двенадцатью
показателями в каждом. Виджеты работают, пока запущена Astra и включён плагин.

## Примеры фраз для ИИ Astra

Устройства:

- «Включи умную лампочку в коридоре»
- «Выключи люстру»
- «Открой багажник»
- «Включи свет в коридоре» — по комнате

Сценарии:

- «Запусти сценарий 1 минута»
- «Запусти двигатель на 15 минут»
- «Какие сценарии есть в умном доме?»

## Расписание через Таймер паузы

Плагин «Таймер паузы» версии 1.1.0 и новее позволяет запускать устройства и сценарии из отдельной вкладки «Умный дом»: на выбранную дату, ежедневно или по дням недели. Оба плагина и Astra должны работать в момент запуска. Для подключения достаточно настроенного аккаунта во вкладке «Умный дом».
