Плагин к Astra от Voltur: живая фоторамка на рабочем столе, работающая без сети. Показывает папки с фото и видео как слайд-шоу на домашнем экране. Поддерживает форматы: фото — jpg, png, webp, gif, bmp, apng; видео — mp4, webm, mov, m4v. Работает на Astra 0.2.7 и новее, требуется Python 3.10 или новее.

Настройка

1. Установка рамки: на домашнем экране Astra → «Панель виджетов» → «Фоторамка». Размер меняется перетаскиванием.
2. Выбор папок: «Настройки рамки» → «📁 Выбрать папку…». Можно добавить до 12 папок.
3. Настройка показа: интервал смены, порядок, переходы, фон, подписи, поведение видео.

* Поддерживается поиск файлов в подпапках (рекурсивно).
* Кадры предзагружаются заранее, обработанные изображения кэшируются.
* Настройки сохраняются внутри плитки Astra.

Вне сети

Плагин работает локально через поток 127.0.0.1. При блокировке — через мост Astra.
