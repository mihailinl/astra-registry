Плагин к Astra от Voltur: живая фоторамка на рабочем столе, работающая без сети. Показывает папки с фото и видео как слайд-шоу на домашнем экране. Поддерживает форматы: фото — jpg, png, webp, gif, bmp; видео — mp4, webm, mov. Работает на Astra 0.2.7 и новее, требуется 64-разрядный Python 3.10 или новее.

Настройка

1. Установка рамки: на домашнем экране Astra → «Панель виджетов» → «Фоторамка». Размер меняется перетаскиванием.
2. Выбор папок: «Настройки рамки» → «📁 Выбор папки…». Можно добавить до 12 папок.
3. Настройка показа: интервал смены, порядок, переходы, фон, подписи, поведение видео.

* Папки и подпапки настраиваются отдельно.
* Кадры предзагружаются заранее, тяжёлые — кэшируются.
* Настройки сохраняются внутри плитки Astra.

Вне сети

Плагин работает локально через поток 127.0.0.1. При блокировке — через мост Astra.
