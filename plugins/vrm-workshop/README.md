# VRM Workshop

Плагин для **Astra** — скачивает VRM-модели из мастерской Steam (без владения игрой) и показывает 3D-превью до сохранения.

## Возможности

- 🔍 **Поиск приложений** по названию (Steam Store API) — клик по приложению открывает каталог его работ.
- 🗂 **Каталог работ мастерской** — сетка с превью, названием и размером; пагинация по страницам.
- 👗 **Скины** — у многих персонажей несколько версий (скинов) одной модели; плагин находит их по имени и позволяет переключиться.
- 🖼 **3D-превью** — модель рендерится прямо во вкладке (three.js + GLTFLoader), можно вращать мышью.
- ⬇️ **Скачивание в Загрузки** — сохраняет выбранный .vrm с понятным именем.
- 🕘 **История поиска** — недавно найденные приложения под рукой, одним кликом открывается каталог.
- 🎙 **Голосовой вызов** — инструмент `download_vrm_workshop` для скачивания по ссылке/ID.

## Как это работает

1. **Поиск приложения** — `store.steampowered.com/api/storesearch/` → appid, название, иконка.
2. **Каталог работ** — парсинг `steamcommunity.com/workshop/browse/` (id работ извлекаются из HTML), детали — через `GetPublishedFileDetails` пачками до 100 id.
3. **Скачивание** — `DepotDownloaderMod.exe -app <appid> -pubfile <id>` анонимно, без владения игрой. Модель ищется по `*.vrm|*.glb|*.gltf` и копируется в кэш.
4. **Превью** — VRM — это GLTF, поэтому three.js рендерит геометрию и текстуры; OrbitControls дают вращение мышью.

## Установка

1. Скопируй папку плагина в каталог проектов Astra:
   ```
   %APPDATA%\astra\astra\data\plugin-projects\
   ```
2. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Перезапусти Astra / перезагрузи плагин — во вкладках появится **VRM Workshop**.

> Требуется **.NET 9** для `DepotDownloaderMod.exe`.

## Использование

- **Вкладка**: найди приложение → кликни по нему → выбери работу → крути модель мышью → «Скачать в Загрузки».
- **Голосом/в чате**: «скачай VRM-модель по ссылке » или «скачай работу ».

## Структура

```
vrm-workshop/
├── plugin.toml          # манифест плагина
├── main.py              # backend (Python, astra-plugin-sdk)
├── requirements.txt     # astra-plugin-sdk>=0.6,<0.7
├── ui/
│   ├── index.html       # страница-вкладка (three.js + GLTFLoader)
│   ├── vendor/          # three.min.js r147, GLTFLoader.js, OrbitControls.js
│   └── cache/           # скачанные .vrm (раздаются по относительному пути)
├── bin/depotdl/         # DepotDownloaderMod.exe + DLL (.NET 9)
└── cache/               # временные папки загрузки dl_<id>
```

## Приватность

Плагин не запрашивает никаких разрешений Astra: всё происходит внутри своей папки, в Загрузки пишет только по явному действию пользователя. Скачивание анонимное.
