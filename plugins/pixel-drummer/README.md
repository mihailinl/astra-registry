# Pixel Drummer

## Совместимость

Linux и macOS — **экспериментальные**. Проверки Python и автоматические тесты не заменяют проверку графики, звука и работы внутри Astra на реальной ОС. Windows сохраняет прежние возможности.

Официальные хосты Astra сейчас доступны для Windows x64 и Linux x64. Код подготовлен также под macOS, но официального хоста Astra для Mac и ARM пока нет: установить и полноценно проверить плагин там внутри Astra нельзя. См. [платформы Astra](https://github.com/mihailinl/AstraPlugins/blob/master/docs/en/1-orientation/platforms.md).

Сцена, выбор инструментов, анимации и деморежимы подготовлены для Linux/macOS. Нужен Python 3.12 или новее и зависимости плагина. Нативные окна и звук вне Windows вручную не проверялись.

- Windows: прежний захват воспроизводимого звука, прогулки по окнам и игра с копиями значков сохранены.
- Linux: для реакции на музыку нужен PulseAudio либо совместимый сервер PulseAudio в PipeWire и библиотека `libpulse`. Для Qt нужны библиотеки вашей графической среды. Под X11 доступно перемещение собственной сцены; взаимодействие с чужими окнами и значками отключено.
- Wayland: X11 принудительно не включается; используется выбранный Qt backend. Автоматические прогулки между экранами отключены. Положение прозрачного окна и показ поверх остальных зависят от композитора.
- macOS: SoundCard не предоставляет встроенный loopback CoreAudio. Для реакции на музыку самостоятельно настройте виртуальный звуковой маршрут и задайте точное имя либо ID его входа в `PIXEL_DRUMMER_LOOPBACK_DEVICE`. Указывайте именно настроенный виртуальный вход для музыки. Без него физический микрофон автоматически не выбирается; доступны деморежимы `slow`, `mid`, `fast`. Перемещение по чужим окнам и игра со значками отключены.

Пакет персонажа находится в конфигурации Astra: Linux — `$XDG_CONFIG_HOME/astra/companion/pack` (по умолчанию `~/.config/astra/companion/pack`), macOS — `~/Library/Application Support/com.astra.astra/companion/pack`. Для нестандартной установки задайте `PIXEL_DRUMMER_PACK`; данные самого плагина можно перенести через `PIXEL_DRUMMER_DATA`. На Windows прежние каталоги сохранены.

Музыкальный компаньон для **Astra**: включите любимую песню — и пиксельная Nayu достанет инструмент и начнёт играть. Без музыки она гуляет по рабочему столу; в Windows иногда забирается на открытые окна.

## Музыка оживает на рабочем столе

- **Четыре инструмента:** барабаны, красная электрогитара, микрофон и синтезатор.
- **Автоматический выбор:** Nayu подбирает инструмент по звучанию музыки; его можно выбрать и вручную.
- **Живые движения:** палочки и руки, спокойные кивки головы, покачивание тела и движения видимых ног.
- **Музыкальные эффекты:** волны от ударов, искры и маленькие летящие ноты. Эффекты работают и у одной Nayu, и на сцене.
- **Вокал:** певица открывает рот, когда распознаётся голос в музыке.
- **Концерт:** четыре Nayu выходят на общую сцену, каждая со своим инструментом.
- **Прогулки:** переходы между мониторами и отдых на верхнем крае окна.

Постоянной панели нет. Правый клик по персонажу открывает меню инструментов, эффектов и прогулок. Левой кнопкой Nayu можно перетаскивать. Размер Nayu совпадает с обычным компаньоном и следует за настройкой Astra «Размер аватара».

## Установка

Нужна **Astra 0.2.7 или новее** с включённым 2D-компаньоном. Windows x64 — основной вариант, остальные ОС экспериментальные; ограничения описаны выше.

Pixel Drummer есть в каталоге плагинов Astra — скачивать архивы и включать режим разработчика не нужно.

1. В Astra откройте раздел **Плагины**, найдите в каталоге **Pixel Drummer** и нажмите **Установить**.
2. Дождитесь, пока Astra подготовит Python и зависимости плагина.
3. Разрешите плагину управлять компаньоном.
4. Включите музыку. Окно Astra можно свернуть, оставив приложение работающим.

Новые версии приходят через каталог, как обновления остальных плагинов.

## Попросите Astra

- **«Собери группу на сцене»** — появится сцена с четырьмя музыкантами.
- **«Убери сцену»** — группа уйдёт, одна Nayu вернётся в автоматический режим.
- **«Пусть Nayu играет на гитаре»** — выбор инструмента.
- **«Выбирай инструмент автоматически»** — возвращение автоматического выбора.
- **«Верни обычную Nayu»** — штатный компаньон Astra.

Запросы можно отправлять голосом или в чате. Инструменты также доступны через меню по правому клику.

## Звук и совместимость

Плагин слушает воспроизводимый на компьютере звук. Физический микрофон автоматически не выбирается; звук анализируется локально, без сохранения аудиозаписей и отправки на сервер. Для анимаций не нужны API-ключи или платные запросы к ИИ.

Ритм и вокал определяются по музыке, поэтому в сложных композициях возможны пропуски или неверное распознавание. Плагин не выделяет отдельные инструментальные дорожки и не распознаёт текст песни.

На время выступления Nayu использует музыкальные анимации. Для штатных сна, погоды и напоминаний выберите **«Вернуть обычную Nayu»**. Прогулки проверены на нескольких мониторах; смешанный масштаб экранов может влиять на положение персонажа.
