# Knowledge Graph — граф знаний Астры

Живой граф в стиле Obsidian по чатам и памяти Астры.

## Что делает
- **Вкладка «Граф знаний»** в навигации Astra: светящиеся узлы-сущности,
  связи-пружины, физика, зум/панорама, драг узлов, поиск, легенда.
- **Источники:** история чатов (`~/.config/astra/chat_history/*.jsonl`) —
  сущности извлекаются из заглавных фраз с нормализацией падежей;
  память (`memory.db`) — готовые тройки subject/predicate/object.
- **Живое обновление:** события `chat_message` / `memory_changed` перестраивают
  граф с задержкой 6 с; страница подтягивает свежую сборку каждые 15 с.
- **Клик по узлу** — панель с выдержками сообщений, где сущность встречается.

## Инструменты для Астры
- `rebuild_knowledge_graph` — перестроить, вернуть статистику.
- `graph_stats` — узлы/связи/сообщения/тройки.
- `find_connections(«А», «Б»)` — цепочка связей между понятиями (BFS).

## Установка
Папка плагина лежит в `~/.config/astra/plugins/knowledge-graph`
(разработка — в `~/ZCodeProject/astra-knowledge-graph`). Нужен режим
разработчика (Settings → Privacy → Allow unsigned plugins).

## Тесты

```
python3 -m pytest tests/ -q
```

## v0.2.0 — три 3D-режима и самобутстрап
- Режимы: **2D** (Obsidian), **3D** (космический force-graph с частицами),
  **Космос** (секторальная система), **Мозг** (анатомические доли).
- Системные данные во всех режимах: плагины, инструменты ядра, команды, MCP, модель.
- Самобутстрап: на машине без `astra-plugin-sdk` плагин сам создаёт `.venv`,
  ставит зависимости и перезапускается — ставится из каталога «как есть».
