# Морской бой для Astra

Интерактивные карты, сохранение партий и три режима: быстрая игра, соперник Astra и игра по сети.

**Linux и macOS — экспериментальные.** Нативные интерфейс, звук и уведомления на этих ОС вручную не проверялись. Официального хоста Astra для macOS/ARM пока нет. Подробности — [PLATFORMS.md](PLATFORMS.md).

## Установка

Скачайте обновление на странице [Releases](https://github.com/Voltur792/astra-sea-battle/releases/latest).

**Для игры с выбранной моделью и голосовых оповещений используйте Source code (zip) через режим разработки Astra.** При ручном импорте `.astraplugin` доступ к чату ограничен.

1. Скачайте **Source code (zip)** из Assets и полностью распакуйте в постоянную папку, например `C:\AstraPlugins\astra-sea-battle`.
2. Найдите папку с `plugin.toml`, `src` и `requirements.txt`. Если ZIP создал вложенную папку, выбирайте её.
3. В Astra: **Настройки → Приватность → Разрешить неподписанные плагины**.
4. Откройте **Плагины → Разработка (Plugins → Dev) → Загрузить плагин → Обзор** и выберите эту папку.
5. Разрешите запрашиваемый доступ и дождитесь установки зависимостей. Для первой установки нужен интернет.
6. Включите плагин и откройте вкладку **«Морской бой»**. После перезапуска Astra копию из Dev может потребоваться включить снова.

Если Python не найден, установите 64-разрядный Python **3.11+** и перезапустите Astra. При ошибке установки проверьте интернет и журнал плагина; установка пакетов в другой Python не меняет окружение Astra.

Для обновления выключите старую копию, распакуйте новую в отдельную постоянную папку и загрузите через Dev. Не удаляйте активную папку. Партии и настройки хранятся отдельно; путь можно изменить через `SEA_BATTLE_DATA_DIR`.

## Режимы игры

- **Быстрая игра** — соперник без расхода ИИ.
- **Против ИИ Astra** — выбранная в Astra модель расставляет свой флот и выбирает ответные выстрелы через обычный чат. Расход зависит от модели и числа ходов.
- **Другой игрок · сеть** — приглашение другу или подбор случайного соперника из другой Astra. Отдельная регистрация и аренда сервера игрокам не нужны. Сетевой режим экспериментальный.

Перед началом расставьте свои корабли вручную или нажмите **«Расставить случайно»**. Нужно 10 кораблей длиной 4, 3, 3, 2, 2, 2, 1, 1, 1, 1; касание запрещено даже углами. После попадания ход продолжается, после промаха переходит сопернику.

Режим запоминается при переключении вкладок. Локальные/AI-партии сохраняются между перезапусками; история ограничена пятью играми. Если модель дважды предложила неправильную расстановку или недопустимый выстрел, плагин использует явно обозначенное исправление или запасной ход. Ошибку связи с провайдером можно повторить.

## Сетевая игра

Обоим игрокам нужна новая версия. В режиме **«Другой игрок · сеть»**:

- **«Создать комнату»** — скопируйте приглашение и отправьте другу личным сообщением. Друг вставляет его и входит в комнату.
- **«Найти игру»** — общая очередь Metered подбирает другого ожидающего игрока и создаёт отдельную комнату автоматически.

После соединения каждый расставляет флот и нажимает **«Готов»**. Соперник не видит вашу расстановку до конца партии. Потопленные корабли раскрываются во время игры. После завершения сверяются исходная фиксация флота и результаты выстрелов; это проверка результата, а не полная защита от изменённых клиентов.

**Поиск работает в фоне**, даже если страницу игры закрыли или выбрали другую вкладку/режим. Он прекращается кнопкой **«Отменить поиск»**, через 3 минуты или при выключении Astra/плагина. После перезапуска приложения поиск нужно включить заново. Индикатор **«В поиске»** считает ожидающих игроков этой версии протокола, включая вас; уже играющие и остальные установки Astra в него не входят. При отсутствии связи показывается неизвестное состояние. Если никто другой не ищет игру, соперник не появится.

### Ник и оповещения

В разделе **«Ник и оповещения»** задайте ник до 32 символов, системное уведомление и один из вариантов: обычный сигнал, голос Astra или без звука. Пустой ник отображается как «Игрок». Ник видит выбранный соперник; в общую очередь он не публикуется и не является проверенным именем аккаунта.

Голос использует выбранные в Astra модель и голос через обычный чат: это дополнительный запрос к провайдеру и запись в чате. При ошибке или таймауте звучит системный сигнал. Уведомление может подавляться режимом «Не беспокоить». На Linux для уведомления нужен `notify-send`, для сигнала — `paplay` и системный звук; работа на реальном Linux/macOS не проверена.

После фонового подбора вернитесь в Морской бой и расставьте корабли. Если второй игрок вернулся позже, может понадобиться **«Переподключиться»**.

**Для передачи самих ходов держите страницу партии открытой.** Закрытие страницы ставит связь на паузу; комната, флот и неподтверждённый выстрел сохраняются локально. Не открывайте одну комнату одновременно в нескольких окнах.

### Соединение и ограничения

Автоматические маршруты: **Metered → PeerJS → ручной резерв WebRTC**. Если сервисы комнат недоступны, создатель передаёт резервное предложение, второй игрок возвращает ответ, создатель принимает его. Коды можно переслать любым мессенджером. Поиск случайных игроков требует работающей общей очереди Metered; резервное приглашение не заменяет её.

WebRTC пытается соединить игроков напрямую, при сложном NAT использует TURN. Без доступного TURN прямое соединение возможно не во всех сетях. Бесплатные сервисы имеют квоты и не гарантируют доступность, в том числе у всех операторов РФ. У общего TURN-проекта пробный лимит **500 МБ в месяц** с остановкой по лимиту;

Передавайте приглашение только сопернику: оно содержит секрет комнаты. В общую очередь отправляются случайный идентификатор и статус ожидания; приглашение доставляется выбранному игроку адресно. Аккаунт Astra, переписка и флот для поиска не нужны.
