# Home Assistant Connector

© 2026 Enti_Edvard

Плагин для подключения Astra к Home Assistant: чтение состояний устройств и вызов сервисов.

## Возможности

- поиск сущностей по имени или `entity_id`;
- получение показаний датчиков через `get_sensor_readings` — температура, влажность, давление, освещённость, заряд батареи и другие значения;
- просмотр полного состояния сущности;
- включение, выключение и переключение сущностей;
- вызов произвольного сервиса с JSON-данными.
- постоянная подписка на события `state_changed` с автоматическим переподключением;
- просмотр до 100 последних изменений через `get_recent_state_changes`.
- встроенная панель Astra со списком сущностей, поиском, состояниями и управлением `light`/`switch`.

## Настройка

В Astra откройте настройки плагина и заполните:

1. **Home Assistant WebSocket URL**, например `ws://homeassistant.local:8123/api/websocket` или `wss://example.duckdns.org/api/websocket`. Адрес должен оканчиваться строго на `/api/websocket`;
2. **Long-Lived Access Token** — создайте его в профиле Home Assistant.

Токен хранится в настройках Astra и не должен попадать в `config.toml`, Git или логи.

Для запросов о текущей температуре, влажности, давлении, освещённости или заряде батареи используйте инструмент `get_sensor_readings`. Он читает только сущности `sensor` и `binary_sensor` Home Assistant и не управляет устройствами. `search_entities` предназначен для общего поиска, а `get_entity_state` — для чтения одной заранее известной сущности по точному `entity_id`.

Плагин ожидает весь ответ Home Assistant (подключение, авторизацию и команду) не более 20 секунд. Для `wss://` используются системные доверенные сертификаты Windows.

По умолчанию плагин не создаёт постоянных фоновых подключений. Если нужен журнал последних изменений, включите настройку **«Проверять изменения для журнала раз в 10 минут»**: плагин раз в 10 минут запросит текущие состояния и сравнит их с предыдущим снимком. Это не создаёт постоянного потока `state_changed`, но журнал обновляется с задержкой до 10 минут и не содержит промежуточных изменений между проверками.

## Панель

В навигации Astra появится страница **Home Assistant** в стиле Overview. Она получает комнаты, распределение сущностей и заданные в Home Assistant MDI-иконки непосредственно из `area_registry`, `entity_registry` и `device_registry`. Комнаты отображаются отдельными вкладками; внутри активной вкладки показываются только её выбранные устройства. Автоматизации, недоступные, скрытые и диагностические сущности, а также служебные сущности платформы `homeassistant` не показываются в панели. Набор устройств можно изменить кнопкой **«Настроить устройства»** — выбор сохраняется локально. Для `light` доступны быстрые переключатели и яркость, для `cover` — открытие, остановка и закрытие штор. Датчики показываются компактно. Журнал отображает последние события `state_changed`.

## Разработка

Требуются Rust и `protoc`.

```powershell
cargo test
astra-plugin check . --strict
astra-plugin test .
astra-plugin dev .
```

## Сборка

```powershell
astra-plugin build
```

Команда создаёт распространяемый файл `.astraplugin`.
